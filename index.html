An API documentation platform where developers can explore endpoints and test them in real time.

A marketplace for discovering independent websites and Android apps made by people who love building.

CODEVERSE is a Play Store-style site built with React and Vite, where creators publish their own websites and apps and anyone can browse them. xeddsapk

Visit site

Turn any website into a ready-to-install Android app in a few easy steps.

xeddsapk is an app studio for packaging a website as an Android app. You give your app a name, an icon, and your website URL, and a live preview shows the site inside a phone frame. Then you add details like the package ID and version, and design a custom splash screen with its own animation, background color, and image. When you’re ready, you send a build request and get an APK back.

It also comes with built-in options:

  • Block ads and prevent unwanted app redirects
  • AdGuard DNS to block ads and trackers
  • Transparent navigation bar
  • Hide scrollbars
  • Pinch to zoom
  • Disable copy text
